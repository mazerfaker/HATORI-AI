# Multimodal roadmap

## v0.6.x
- Microphone speech recognition and spoken responses; local/offline options.
- Image attachments, Ctrl+V clipboard images, drag and drop, multimodal model routing.
- File attachments and document analysis.

## v0.7.x
- Search user-authorized local folders and return original files as chat attachments, regardless of extension.
- Create and edit files with explicit permission; confirm destructive operations and external transfers.
- Keep file access local by default, show paths and access history.

These are planned features, not implemented. Preserve Windows autostart and shared mobile architecture.
