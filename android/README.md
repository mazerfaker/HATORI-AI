# Hatoriel Android Native Chat 0.4.1
Native ARM64 Android chat using the shared Rust prompt/context core through JNI. Java transport uses Ollama /api/chat (streaming NDJSON) with a user-selected endpoint. Default is http://127.0.0.1:11434, which refers to the Android device itself, not the user's PC. No runtime or model is bundled. A working compatible server is required. HTTP is allowed only on loopback; external servers must use HTTPS with a trusted certificate. Redirects are disabled. Configure and confirm the endpoint before sending. Recent history and user message are transmitted to that server; server-side retention is outside this application's control.
History is stored in private SharedPreferences, limited to 100 messages. No encryption beyond Android storage protections; no backup or cross-device sync. History can be cleared with confirmation. The UI supports cancellation of client requests, but does not guarantee cancellation of server computation. Rotation or activity destruction cancels the active request; the submitted user message remains in history.
Build: Android API 26+, ARM64, SDK 35, Java 17, Gradle 8.9, AGP 8.7.3, NDK 27.2.12479018. GitHub Android CI produces Hatoriel-Android-ARM64-Debug on success. No Gradle wrapper or release signing yet. See workflow for native library packaging steps.
