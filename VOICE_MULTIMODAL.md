# Hatoriel 0.6.0 — Voice Foundation Preview
Base: verified successful v0.5.9 commit 861490d (Windows 349, Android 237, iOS 115). Preserve Crimson Core Minimal and all existing inference/storage features.
- Windows: manual reading of last assistant message using installed System.Speech via Windows PowerShell; fixed command, message via UTF-8 stdin, no shell interpolation; stop kills child; cap 4000 characters. No Windows STT yet. Availability of Ukrainian voice depends on installed SAPI voices.
- Android: explicit confirmation before launching system RecognizerIntent; requests offline preference but the provider may ignore it. No automatic submission. Draft appended with cap. Local TTS selects a voice marked not network-required and installed, supports Ukrainian/English, manual play/stop. No mic access directly by app, no recording stored by app. Provider privacy is separate.
- iOS: explicit system permissions, Speech recognition requires on-device capability, 45s recording limit, cancel on scene inactivity, editable draft copied explicitly, system AVSpeechSynthesizer manual play/stop. Speech permissions/voice availability depend on device. No background recording. No audio sent to Hatoriel AI endpoints.
- Next stages: desktop STT, speech feedback state integration, multimodal file ingestion and vision, document extraction. No image analysis or attachments in 0.6.0.
- Acceptance: CI for all three platforms; device tests for permission denial, unsupported language, audio route and interruptions, start/stop, offline availability, draft preservation, and no automatic send. Voice runtime not yet verified. Manual user test deferred to 1.0.

## 0.6.1 Desktop Speech Recognition
Windows local System.Speech desktop recognizer using an explicitly chosen uk-UA/en-US culture, default Windows audio input device, manual start/finish or in-window hold-to-talk. Device selection is through Windows Sound Settings, not a direct microphone picker. No global hotkey, no cloud fallback, no audio files stored by Hatoriel. Requires an installed matching desktop SAPI recognizer; Ukrainian availability is not guaranteed. Windows speech capture has a 45-second recording limit and process watchdog, explicit cancel, focus/page-loss cancellation, bounded UTF-8 transcript protocol and draft insertion only on approval. TTS stops before capture; sending and playback disabled while recording. This is not Whisper integration yet. Two new Rust regression tests for protocol and bounded Unicode draft. Mobile source features unchanged; version numbers aligned. Previous v0.6.0 CI passed Windows #350, Android #238, iOS #116. New CI and actual microphone runtime remain pending.
