# Hatoriel 0.4.9 — Stability Preview

## Implemented static changes
- Extracted bounded NDJSON parsing; validates terminal event, cancellation, Unicode, final line and size limits. Request body and port checks.
- Android tests: 7 JVM test methods covering endpoint restrictions, Unicode/final line, truncated/empty/error streams, cancellation, response bounds.
- Android CI now runs JVM tests and lint before APK assembly and uploads QA reports even on failure.
- Reticle respects Android animation enable setting, reduces idle cadence, stops redraw scheduling while hidden or detached. Desktop idle repaint reduced to 10 Hz.
- Android keyboard hides bottom navigation; system insets explicitly managed on API 30+.
- Generation IDs randomized per process to reduce stale notification collision. Service start bound to requested job; cancellation idempotent. Model import checks cancellation before rename. Session key input not saved in view state.
- Approved Minimal identity and existing features retained in source.
