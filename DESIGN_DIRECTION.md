# Hatoriel visual identity
User preference: black as the primary color, a restrained burgundy secondary accent. Preserve readability; avoid teal as a default brand accent in the eventual redesign.
Proposed dark tokens (subject to visual review): background #09090B, surface #161417, elevated #201B1E, burgundy #68263A, accessible rose accent #CE8297, text #F4F0F2, secondary text #B5AAB0. Burgundy is for selected controls and accents, not large bright backgrounds.
0.4.1 introduces these tokens on Android. A comprehensive redesign of Windows, Android and future iOS, including avatar, logo, typography, animations and accessible contrast, remains a dedicated design task. No automatic asset replacement or rename of internal data paths.

## Approval gate (user requirement)
Before implementing the comprehensive redesign, present multiple visual concepts and interactive, clickable prototypes for Windows and Android for user review, including chat, memory, settings, navigation, avatar and responsive layout. Wait for explicit approval of the chosen concept before modifying the production UI, logo, avatar or global theme. Keep technical development separate. The current 0.4.1 palette is a provisional baseline, not an approved final design. Future iOS should follow the approved identity.

## Approved avatar — Crimson Core
User approved the abstract animated red reticle (crosshair), replacing the H-in-circle concept. Black and graphite surfaces, true red accents (no pink), restrained cyber-gothic styling, slightly lighter surfaces for readability. The approved avatar prototype uses breathing at idle, rotating rings during processing, response pulses, listening motion, positive glow and error glitch. Reuse as app symbol, desktop avatar, generation indicator and tray icon where appropriate. Avatar concept approval is not full UI approval: provide visual concepts and clickable Windows/Android prototypes for explicit approval before production redesign. The previous rose accent is superseded as design direction, not yet changed in production.

## Approved design — 01 Minimal (0.4.8)
After seeing detailed Windows and Android concept comparisons, the user selected Minimal. This approves integration of the selected concept, not Crimson Gothic or Cyber HUD. Production implementation uses black/graphite surfaces (#141416, #1C1C1E, #2B2B2E), neutral white text (#F2F2F2), true red (#EE3434), and a muted red selection fill. No pink, teal, gothic artwork, decorative dashboards or intrusive HUD. Windows and Android retain existing features. The reticle is procedurally animated in idle and active generation; voice/listening and other emotional animations are pending. The Windows light theme is preserved as an optional legacy setting. Actual native screenshots, accessibility/contrast review, CI and device verification remain pending; generated concepts are not screenshots of the build.
