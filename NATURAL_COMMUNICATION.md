# v0.8.7 Natural Communication

Shared transient conversation hints recognize explicit topic changes, corrections, acknowledgments, continuations, and repeated three-word openings from recent assistant replies without copying old assistant content into system instructions. Dynamic style can be disabled; saved traits and profile are unchanged. Latest substantive user turn controls task inheritance; explicit no-humor requests suppress both humor and sarcasm.

Windows/Android/iOS align simulated mood intensity with technical/research tasks when emotion and dynamic style are enabled. Windows automatic TTS uses a mild bounded pace adjustment for the same mood; manual speech remains unchanged. Mobile TTS pacing is not changed. No audio-driven lip sync, actual emotion inference or fine-tuning. Prompt guidance can reduce repetition but is not a guarantee of local model output.

Tests cover topic transitions, corrections, repetition detection, latest-topic inheritance, humor suppression and mood/voice bounds. Physical-device and subjective conversation quality testing remain separate.
