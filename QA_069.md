Base: 02268d425ec2e8d23babb80a716f9bf14b4d8e89. Previous v0.6.8 Android core + JNI unit tests passed; Windows/iOS pending at inspection. Intermediate CI runs cancelled by subsequent pushes are not successful builds.

## Required automated gates
- Windows: core check/test, desktop check/test, release EXE, installer, portable archives.
- Android: Rust core/JNI unit tests, arm64 JNI release, JVM tests, lint, debug APK.
- iOS: Rust core/FFI tests, native llama and Rust XCFramework, simulator and unsigned device builds.
- Inspect actual failure logs and rerun only with necessary fixes; no v0.7 feature changes before all gates pass.
- Confirm non-expired artifacts for same commit.

## Runtime QA checklist (not executed)
- Windows: speech permissions/installed locale, PTT release and focus loss; system TTS, Piper with installed runtime/model, stop/cancel and temp WAV cleanup.
- Android/iOS: dictation permission/cancel, explicit send, local voice availability, background suppression and reduced motion.
- Attachments: 4/8 MiB/24 MiB limits, malformed images, PNG/JPEG thumbnails, clipboard and drag/drop on Windows; mobile pickers; failure retains desktop draft.
- Vision: trusted local Ollama with installed vision model, reject nonvision model; mixed document/image request; cancellation and output bounds.
- Documents: UTF-8/UTF-16, bounded DOCX, installed pdftotext with text-layer PDF, no OCR; lexical ranking, review, context overflow and no raw reference persistence.
- Long sessions: memory measurements, repeated capture/playback/import, lifecycle and audio interruption. No soak or real hardware measurements have been run here.

## Known limitations
Mobile multimodal analysis not implemented. Piper and pdftotext not bundled. System STT/voice locale availability depends on OS. No full-duplex/wake word, measured audio waveform, OCR or vector document retrieval. iOS unsigned. Character budgets approximate token limits. Local endpoint trust is required.
